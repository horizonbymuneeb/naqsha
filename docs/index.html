A free diagram skill for coding agents: ten diagram types, ten native layouts, and a self-contained HTML artifact with tours, search, route tracing, diffs and export — no network, no fonts, no hosted service.

  • tree Repository layout The directory hierarchy at v3.2.0, one parent per node.

  • waterfall Finalize run Measured wall-clock spans for each gate on this machine.
  • dataflow Repository evidence From source files to source-backed nodes, stage by stage.
  • lifecycle Artifact lifecycle Candidate → gated → published, or the last good file kept.
  • mermaid Ingested Mermaid A sequenceDiagram converted to IR and re-rendered.
Every page is a single self-contained HTML file — no CDN, no fonts, no telemetry. Use / to search, r to trace a route, p for the presentation laser, ? for all bindings.
